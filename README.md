# Script SQL de creación de tablas y relaciones 

# Problemas a resolver: 
1. Registrar huertos, parcelas y tipos de cultivos 
2. Registrar las siembras realizadas, incluyendo fecha y cantidad 
3. Controlar el estado de los cultivos: sembrado, en crecimiento o cosechado 
4. Registrar las cosechas y consultar el historial por parcela 
5. Obtener reportes de producción agrícola por cultivo y periodo
